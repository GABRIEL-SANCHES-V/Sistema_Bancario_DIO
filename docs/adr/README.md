# ADR — Architecture Decision Records

Esta pasta contém os **Architecture Decision Records (ADR)** do projeto.

ADRs são documentos curtos que registram **decisões arquiteturais importantes** tomadas durante o desenvolvimento do sistema.

Registrar essas decisões ajuda a:

- entender o **porquê das escolhas**
- manter **consistência arquitetural**
- facilitar **onboarding de novos desenvolvedores**
- evitar decisões conflitantes no futuro
